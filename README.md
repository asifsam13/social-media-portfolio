# Social Media Portfolio Website

A professional portfolio website for social media managers showcasing expertise in viral content creation, community building, and brand growth strategies.

## 🚀 Features

- **Responsive Design**: Optimized for desktop, tablet, and mobile devices
- **Professional Landing Page**: Compelling hero section with key statistics
- **Service Showcase**: Detailed overview of social media management services
- **Portfolio Highlights**: Success stories with metrics and results
- **Working Contact Form**: Interactive form with validation and user feedback
- **Modern UI/UX**: Clean design with smooth animations and professional styling

## 📋 Sections

1. **Hero Section**: Eye-catching introduction with key statistics (5+ years experience, 100+ campaigns, 500% average growth)
2. **About Me**: Personal story and core skills (Instagram, TikTok, Facebook, Video Content, Analytics, Community Building)
3. **Services**: Six main service offerings from content creation to growth strategy
4. **Portfolio**: Three featured case studies with impressive results
5. **Contact**: Working contact form with social media links

## 🛠️ Technologies Used

- **HTML5**: Semantic markup for accessibility and SEO
- **CSS3**: Modern styling with flexbox, grid, and animations
- **JavaScript**: Interactive features and form validation
- **Font Awesome**: Professional icons throughout the site

## 🎨 Customization

### Personal Information
Update the following in `index.html`:
- Hero section statistics and description
- About section personal story and skills
- Contact information (email, phone, location)
- Social media links

### Portfolio Projects
Replace the placeholder portfolio items with your actual work:
- Update project titles and descriptions
- Add real metrics and results
- Replace placeholder images with actual project screenshots

### Color Scheme
The main brand colors can be updated in `styles.css`:
- Primary color: `#e91e63` (pink)
- Secondary gradient: `#667eea` to `#764ba2` (blue to purple)
- Background colors and text colors

### Content
All text content can be easily updated in the HTML file to reflect your specific experience, services, and achievements.

## 🚀 How to Use

1. **Local Development**: Open `index.html` in your web browser or serve it with a local server
2. **Hosting**: Upload the files to any web hosting service (GitHub Pages, Netlify, Vercel, etc.)
3. **Customization**: Edit the HTML, CSS, and JavaScript files to match your personal brand
